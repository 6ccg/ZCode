# 修改版内置官方联网能力

## 范围与规则

- Sites（上传部署包、站点管理）和 Image Search（官方 MCP 查询）有真实外部端点，默认关闭。设置中仍可手动启停、卸载或恢复所属插件，市场浏览、主动安装和用户配置的模型 API/MCP 保持可用。
- 插件配置仍由既有插件配置入口唯一拥有，不新增环境变量或另一套权限存储。CLI 与设置页的默认集合一致；用户已有显式启用配置遵循其配置，缺省不得启用。
- 关闭不只隐藏入口：新 runtime 不加载其技能、命令、MCP；旧 runtime 发起官方 HTTP MCP 请求或 Sites 本地代理请求时重新读取插件启用状态，关闭或读取失败时在发放身份、发送请求前拒绝。禁止匿名回退绕过关闭。
- 纯本地文档、可视化、工作流技能不因内置身份而停用。此规则不构成 Bash、浏览器或用户自装代码的全局网络沙箱。

```text
设置 → 既有插件配置 → 新 runtime 的技能/工具发现
                  └→ 每次官方出站请求读取当前状态 → 关闭：拒绝（0 次外部请求）
                                                  → 开启：原有 origin/身份/请求链路
```

## 验证

1. 缺省配置不加载 Sites 和官方搜图；设置与 CLI 默认状态相同。
2. 显式开启后能力可用，关闭后不再发现；插件市场条目仍可浏览。
3. 模拟旧会话调用：关闭后 HTTP MCP、Sites 代理均不访问外部 fetch，也不请求身份头；设置读取失败同样拒绝。
4. 显式开启时保留原有调用；用户提供的普通 MCP、模型 API 不受此开关影响。
